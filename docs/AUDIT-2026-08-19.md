# Khora audit — 2026-08-19

A module-by-module read of all 23 modules (~17k lines) by eight parallel readers,
plus three reconciliation passes (docs vs code, the two red tests, build machinery).
This is the ground truth the README status table is built on.

**Confidence key**

| Mark | Meaning |
|---|---|
| **[V]** | Verified in this session by reading the source or running the binary. Treat as fact. |
| **[P]** | Established by a reader that compiled and ran a probe against the real source. Strong, not independently re-checked. |
| **[R]** | Reported from a source read only. Plausible, unconfirmed. Check before acting. |

## 1. The single highest-leverage defect

### `bundle()` is not a majority vote on even inputs — and for n=2 it is a bitwise OR **[V]**

`src/lattice/glyph.cpp:194` sets `threshold = (n + 1) / 2`. For even `n` that is
`n/2`, i.e. "at least half", so ties resolve toward SET. At `n == 2` the threshold
is 1 and `glyph.cpp:169-175` hard-codes the consequence, honestly commented:

```cpp
if (n == 2) {
    // threshold (2+1)/2 = 1  ->  bit set if either input has it (OR)
    for (std::size_t w = 0; w < kGlyphWords; ++w) ow[w] = A[w] | B[w];
```

`ARCHITECTURE.md` §4.2 specifies "majority sum across inputs". Superposition of two
~50%-dense glyphs should stay ~50% dense; OR takes it to ~75%. Three layers inherit
this:

- **Lexicon** `glyph_for` bundles exactly two glyphs, so context can only ever *add*
  bits. Measured glyph density 0.677, and only a 0.025 similarity gap between an
  always-adjacent pair and a never-co-occurring pair — distributional meaning is
  nearly absent. **[P]**
- **Reverie** computes `dream = bundle({a, b})`, pinning familiarity near zero, so
  satisfaction collapses to a constant 0.60 against a 0.5 threshold. The loom
  therefore retains **100% of dreams, forever**, into a lattice the Ballast governor
  does not know exists. **[P]**
- **Cogitator** `cogitator.cpp:1168` bundles inside a 4-iteration retry loop, driving
  the probe 0.5 → 0.75 → 0.94 → 0.996 density. By attempt 4 the probe is nearly
  all-ones and its similarity to everything collapses to ~0. The comment says
  "enrich the probe"; the code performs set union. **[P]**

No test catches it: `tests/lattice_test.cpp:82` only ever bundles 3 glyphs — the odd,
unbiased case. **[V]**

Fixing the threshold and defining a tie rule is the highest-leverage single change in
the repo, and it invalidates every downstream measurement, so it has to come first.

## 2. The two red tests — both root-caused outside the module they name

### `CrystallizeTest` — 6 of 9 assertions

Not unfinished WIP in `crystallize.cpp`. The root cause is `Plexus::ppmi_`
(`src/plexus/plexus.cpp:53-68`) — **[V]** on the code, **[P]** on the measured effect:

```cpp
const double p_ab = static_cast<double>(cab) / W;   // W = total_cooc_
const double p_a  = ca / N;                         // N = total_tokens_
const double p_b  = std::pow(cb, kContextSmoothing) / std::pow(N, kContextSmoothing);
```

Two problems. The smoothed context distribution must be normalised by the sum of
`c_x^α` over all types, not by `N^α` — so `p_b` is systematically overestimated. And
`p_ab` is divided by the co-occurrence total `W` while `p_a` is divided by the token
total `N`, mixing two different denominators.

Measured effect on the crystallize corpus: every score deflated by ~0.901 bits.
Because PPMI clamps at zero, this does not merely shift scores — it deletes every pair
below the offset, and `Plexus::associates()` returns **empty for all 8 non-rare test
words**. Crystallize is starved of input, not unfinished. **[P]**

This graph also feeds cogitator's abstraction tower and `infer_path`'s beam search, so
the whole symbolic layer is running on a near-empty graph.

### `BulwarkTest` — the runaway assertion

The cage works. Running `bulwark_probe.exe` directly: **[V]**

```
[ok]   contained command launches and is captured
       achieved token tier: 2 (low-integrity, non-admin)
[ok]   write to C:\Windows DENIED by containment
[FAIL] runaway not killed by the job
achieved containment tier: 0  (FAILED — autonomous exploration WITHHELD)
```

The canary is `ping -n 30 127.0.0.1`, hardcoded at `tests/bulwark_test.cpp:19` and
`src/bulwark/bulwark.cpp:281`. On this host: **[V]**

```
CommandType  Name      Source
Application  ping.py   C:\Program Files\Python312\Scripts\ping.py
Application  PING.EXE  C:\Windows\system32\PING.EXE
```

`PATHEXT` includes `.PY` and Python's `Scripts` directory precedes `System32`, so
`cmd` resolves `ping` to impacket's `ping.py`, which dies instantly on an `inet_aton`
error. The "runaway" is not a runaway: it exits in milliseconds, the timeout never
fires, and the Job Object tree-kill is never exercised. A replacement measured to
work: **[P]**

```cpp
// Shell-builtin spin in a GRANDCHILD cmd: cannot be PATH-shadowed, and killing it
// proves the job reaps the whole tree rather than just the direct child.
execute_contained("cmd /c for /l %i in (0,0,1) do @rem", 1500);
```

**The consequence is the important part:** `self_check()` reports tier 0, and
`khora_main` hard-gates the Maw on `self_check() >= 2`. The entire chaos-exploration
drive is unreachable at runtime — killed by a PATH collision, not by a containment
failure. **[V]**

> A separate reader claims a deny-only `BUILTIN\Administrators` SID with an unrepaired
> default DACL makes contained children die at `0xC0000142` before `main`, and supplies
> a Chromium-style `grant_self_in_default_dacl` fix. **This does not reproduce here** —
> tier 2 is achieved and output *is* captured. Recorded for completeness; do not apply
> without first re-establishing the symptom. **[R]**

`README.md` was rewritten against this audit; `ARCHITECTURE.md` has not been.

| Doc claims | Reality |

## 5. Architecture-level concerns

- **One process-wide `std::shared_mutex` serialises eight background loops** (reverie,
  whetstone, ballast, furnace, curiosity, maw, curator, volition) plus the REPL.
  Reverie holds it in *unique* mode for a full O(N) label snapshot plus an
  O(associations) cortex scan per dream cycle. The unused synapse bus was the intended
  decoupling. This is the hard ceiling on throughput. **[R]**
- **Live data race with data-loss potential:** `khora_main.cpp:2813` calls
  `Aqueduct::forage_search` with no lock held (comment: "network — no lock held"), and
  that path `push_back`s/`erase`s `Reservoir::tomes_` while the CuratorScheduler thread
  iterates the same vector. None of the five memory-governance classes has internal
  synchronisation. **[R]**
- **`reverie_pause` joins the worker while holding the lock the worker is blocked on** —
  a reachable deadlock. **[R]**
- **`Lodestone` and `Ballast` wrap their only real measurement in `#ifdef _WIN32`**, so
  off Windows the memory governor is a permanent no-op reporting "normal" at 100% RAM.
  Combined with the uncapped reverie lattice and the linear-growth cortex, there is no
  working backstop against unbounded memory growth on any non-Windows build. **[R]**
- **`Lattice::query` is non-deterministic in ties**: matches are gathered in
  `unordered_map` iteration order and sorted with a non-stable `std::sort`, so
  equal-Hamming ordering varies with hash seed and insertion history. For a system
  selling deterministic LLM-free reasoning, that is a real hole. It also fully sorts
  every stored glyph and then truncates to k, where `nth_element` would do. **[V]**
- **The self-improvement loop may be mathematically inverted**: crucible and whetstone
  permute-then-bind at encode but bind-then-permute at decode (`crucible.cpp:58` vs
  `:116-118`; `whetstone.cpp:358` vs `:299-302`), so escalating the redundancy
  parameter would inject noise instead of signal and could only *lower* the score it
  exists to raise. `evolve()` would then revert nearly every mutation by construction.
  Neither module has a test. **[R] — high value to check; it would explain a lot of the
  flat capability curves in the changelog.**
- **Ligature's sentence handling**: head-noun extraction is correct within a sentence,
  but its only caller feeds it punctuation-stripped whole books, so the 5-word object
  window runs into the next clause. "a sparrow is a small bird. friction causes heat."
  yields `IS-A(sparrow, heat)`. Every false triple poisons the taxonomy that BFS
  reachability, `deduce()` and crystallize all build on. Sentence-boundary tokenisation
  is a small fix with outsized effect on knowledge quality. **[R]**
- **`cogitator::contemplate()`** is documented as multi-threaded cognition and is a
  single-threaded loop using its `threads` argument as a magic multiplier.
  `predict_candidates()` returns k duplicates of one context instead of k alternatives,
  silently making the `compose` tool's topic-steering a no-op. **[R]**

## 6. Build and quality machinery

- **No CI of any kind.** No `.github/`, no pipeline file anywhere in the tree. Two
  tests are red on `main` and nothing announced it. **[V]**
- **Warnings are not errors.** `/W4 -Wall -Wextra -Wpedantic` are set; `/WX` and
  `-Werror` are not, anywhere. A warning ratchet that ratchets nothing. **[V]**
- **No sanitizers.** Zero `sanitiz`/`ASAN`/`UBSAN` hits across all CMake files — in a
  codebase doing raw Job Objects, token manipulation, D3D11 compute buffers, binary
  persistence codecs and self-modifying binary promotion. **[V]**
- **10 of 23 modules have no test**: ligature, hand, maelstrom, cogitator, crucible,
  whetstone, curator, lodestone, ballast, volition — plus all 3353 lines of
  `src/morphus`. Coverage is inverted relative to risk: the tested modules are the
  small stable ones. **[V]**
- **One benchmark for 23 modules** (`bench/lattice_bench.cpp`), not registered with
  ctest, no machine-readable output, no tracked baseline. A 10× regression in
  cogitator, plexus, reservoir or maelstrom would be invisible. **[V]**
- **No `TIMEOUT` or `WORKING_DIRECTORY` on any `add_test`**, and tests write into the
  tree they inherit (`build/tests/data/bulwark` persists between runs). A hung test
  blocks the loop forever; state leaks across runs. **[V]**
- **`khora_main.cpp` (171 KB) is compiled twice**, for `khora` and `khora_next`, with
  byte-identical flags — 7.6 s and 7.5 s, the two slowest compiles in a 10.7 s build.
  The two targets also duplicate a hand-maintained 17-library link list verbatim. **[P]**
- **All 22 library CMakeLists repeat**
  `target_include_directories(... ${CMAKE_SOURCE_DIR}/include)`. `CMAKE_SOURCE_DIR`
  (rather than `PROJECT_SOURCE_DIR`) breaks the moment Khora is consumed via
  `add_subdirectory` or `FetchContent`. **[V]**
- **`KHORA_USE_AVX2` is ON with no runtime check.** On a CPU without AVX2 the build
  succeeds and the binaries die with an illegal instruction — a failure that looks like
  a code bug rather than a config choice. Ten lines of `__cpuidex` at startup would
  make it legible. **[V]**

## 7. Suggested order of attack

Foundational-first, per the backlog's own standing directive. Each item is gated on
the one above it.

1. **Fix `bundle`'s tie rule** and add tests for even `n`. Everything measured
   downstream is currently measured through a broken primitive, so this comes before
   any capability work. Re-run the crucible/whetstone baselines afterward and expect
   the numbers to move.
2. **Fix `Plexus::ppmi_` normalisation.** This turns CrystallizeTest green and
   un-starves the whole symbolic layer — the association graph that cogitator's tower
   and `infer_path` both run on.
3. **Fix the Bulwark canary** (`tests/bulwark_test.cpp:19` and `bulwark.cpp:281`).
   Two-line change; restores tier 2 and un-gates the Maw. Fix `bulwark_probe`'s
   inverted exit code while in there.
4. **Verify or refute the crucible/whetstone encode/decode inversion.** If it is real,
   the entire self-improvement loop has been running backwards, and that is the most
   consequential open question in the repo.
5. **Decide synapse's fate** — wire it in as the decoupling for the global mutex, or
   delete it. Its continued existence as tested-but-unused code is the clearest signal
   of drift between the architecture and the build.
6. **Tests for cogitator**, the largest module in the repo and currently the least
   verified.
7. **Quality machinery**: `TIMEOUT` on every test, a `KHORA_WERROR` option, an ASan
   build config, and a tracked bench baseline that fails the build on regression.

Items 1–3 are small, well-localised, and each has a specific file:line. Item 4 is the
one worth a careful independent check before touching anything.
